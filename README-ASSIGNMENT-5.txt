4. Internet access is needed for Bootstrap 5 CDN styling and components.

ASSIGNMENT 5 FEATURES ADDED
- Heritage Explorer: object array, category filtering with switch, filter(), forEach(), DOM creation, textContent.
- Image explorer: thumbnail buttons update the featured image src and caption; arrow keys navigate thumbnails.
- Expanded gallery and heritage data with the supplied Katon-Karagay, Charyn Canyon, Mangystau, traditional dress, instruments, gathering, and historical-legend images.
- Cultural audio player on the Home page with two supplied tracks, track selection, play/pause, and stop controls. The Gallery page stays focused on images; the shared Play Heritage Sound button remains available on every page.
- Audio playback is coordinated so the full-track player and the shared sound button do not play over one another. Audio never autoplays; users start playback explicitly.
- Multi-step Contact form with Next/Back navigation, input validation, and a callback that switches the visible step while preserving entered values.
- Keyboard navigation: left/right arrows, Home, and End move focus through navigation links.
- Day/Night theme toggle using a CSS class.
- User-triggered heritage audio playback; audio tracks are coordinated to prevent overlapping playback.
- CSS transitions and card entrance animations, with reduced-motion support.
